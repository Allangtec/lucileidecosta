# 🧠 Lucileide Costa — Psicóloga

Site institucional desenvolvido para apresentar os serviços, áreas de atuação e formas de atendimento da psicóloga Lucileide Costa.

## 🚀 Sobre o projeto

O projeto é um site institucional moderno e responsivo desenvolvido para fortalecer a presença digital da profissional e facilitar o contato com pacientes.

O site apresenta informações profissionais, serviços oferecidos, atendimento online e presencial, perguntas frequentes, depoimentos e formas de contato.

## 🛠️ Tecnologias

* HTML
* CSS
* JavaScript
* Google Maps
* Integração com WhatsApp
* Design responsivo

## ⚙️ Funcionalidades

* 👩‍⚕️ Apresentação profissional
* 🧠 Áreas de atuação
* 💬 Informações sobre psicoterapia
* 💻 Atendimento online
* 🏢 Atendimento presencial
* ❓ Perguntas frequentes
* ⭐ Depoimentos
* 📱 Integração com WhatsApp
* 📍 Localização via Google Maps
* 📱 Layout responsivo

## 🌐 Hospedagem

O projeto utiliza hospedagem web para disponibilização do site e serviços externos para algumas integrações.
